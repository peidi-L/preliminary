# Preliminary submission

This repository contains the preliminary files for mutong's team:

- `manifest.json`
- `design/skills_design.md`
- `skills/career_survival/SKILL.md`

The ZIP for upload should contain one top-level `preliminary/` folder with these three files. Check that the team name on the competition site is `mutong's team` before uploading.

The design covers the full path from the simulation input, through the single-agent decision process and MCP tool selection, to the validated tool call returned to the simulation. The competition API key must only be stored in the local environment and must never be committed to this repository.
